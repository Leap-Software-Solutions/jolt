# Typography

Jolt uses Manrope Variable for both body and headings. The font is bundled with the package through `@fontsource-variable/manrope`, so applications do not need a separate font install.

## Hierarchy

Use a restrained hierarchy and let spacing do most of the work. Headings are semibold with tight tracking; body copy uses the normal weight.

## Tokens and utilities

- `font-sans` — Manrope for body text and controls.
- `font-heading` — Manrope for display and section headings.
- `font-mono` — the system monospace stack for code and identifiers.
- `text-muted-foreground` — secondary copy and hints.
- `text-destructive` — validation and destructive status.

Numbers that change in place, such as progress values and sliders, use `tabular-nums` so the layout does not jump.

## Writing

- Use sentence case for headings, labels, and buttons.
- Keep labels short and specific.
- Prefer a verb in actions: "Save changes", "Send invite", "Delete asset".
- Put the consequence in the supporting text, not in the button label.
- Avoid all caps and decorative letter spacing.
